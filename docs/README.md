# Aestas — Documentation

Educational docs for the Aestas app. They assume basic familiarity with web apps and are written so you can follow how everything was built.

1. **[01-overview-and-setup.md](01-overview-and-setup.md)** — What the app does, technology stack, project layout, how to run (Docker and dev).
2. **[02-google-oauth-setup.md](02-google-oauth-setup.md)** — Create a Google OAuth 2.0 client and set the redirect URI.
3. **[03-oauth-and-sessions.md](03-oauth-and-sessions.md)** — OAuth flow step by step and Redis sessions.
4. **[04-database-and-onboarding.md](04-database-and-onboarding.md)** — PostgreSQL schema and the onboarding API.
5. **[05-docker-and-ci.md](05-docker-and-ci.md)** — Docker Compose and GitHub Actions CI.
6. **[06-pre-commit.md](06-pre-commit.md)** — Pre-commit hooks and how to use them.

Start with **01-overview-and-setup.md** if you’re new to the project.
